The epic waits for a person: {{operator}} decides. No agent works this stage.
The epic carries the question and the options, written by whoever sent it
here; if it does not, ask them before deciding.

The epic leaves once the answer is on it, as a note. The stage has no
outcomes; the person answering moves it (`yardr review`, or
`yardr bead advance <epic> --to <stage>`):

- to `open`, when the epic can go on; an answer that needs work is a new
  child, added first, which the epic then waits for;
- to `backlog`, when the answer changes what the epic is and it must be
  reshaped.
