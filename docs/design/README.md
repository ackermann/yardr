# Design documents

Designs from the yard's design lane. Each is the proposal as decided on
its date, kept as it landed and not rewritten, except for a line added
later saying it was withdrawn or replaced, and a link dropped when the
file it pointed at left this folder; a design that replaces another says
so in its first line.

The designs of the hosted service are not in this folder. A design here
may cite one by its bead id: that names the decision and is no link to a
file that is here.

Files are named `<date>-<bead>-<short-name>.md` so the folder lists in
the order the designs were decided.
